## Vinyl interaction references

Reviewed public project descriptions for interaction direction:
- https://github.com/codrops/RecordPlayer — interactive old-school record player using Web Audio.
- https://github.com/pranav1211/mynyl — vinyl-style player and tonearm interaction.

The portfolio implementation is custom vanilla CSS/JavaScript; no third-party code, music, or artwork was copied. The rendered sleeves and printed discs are CSS crops of the user's original 8c375.png and bb38d.png mockups. Play slides the disc out, tilts the sleeve, cues the tonearm and rotates the original printed disc. 33 1/3 and 45 RPM affect rotation only, preserving original audio speed. Existing local audio loading remains optional; no audio is bundled.
